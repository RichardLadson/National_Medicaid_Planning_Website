# Website assets

The four family images use the second, composition-matched photo set. They are AI-generated family scenes. WebP encoding reduces download size without changing the image crop or layout. Original edit masters remain in the supplied image package.

- `assets/photos/01-hero.webp`: 1448 × 1086 pixels; 209,216 bytes.
- `assets/photos/02-care-now.webp`: 1317 × 1194 pixels; 170,232 bytes.
- `assets/photos/03-planning-ahead.webp`: 1317 × 1194 pixels; 168,524 bytes.
- `assets/photos/04-family-next-step.webp`: 1699 × 926 pixels; 217,686 bytes.

The logo is the supplied original. `assets/photos/richard-ladson-original.jpg` is an optimized 1800 × 1197 pixel copy of Richard’s supplied 5971 × 3973 pixel photograph (`Richard Ladson-2.jpg`). It replaces the small portrait taken from the mockup. The photograph is resized and JPEG-compressed without retouching; CSS provides a square frame that keeps Richard’s full face and hair visible. The original source file is preserved outside the website. Icons, divider and process numbers are individual SVG files from the asset pack. Simple layout borders remain CSS. No full-page mockup image is loaded by the website.
